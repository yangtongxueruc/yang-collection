Man Group 的 Token 支出为何暴增 86 倍：从「研究增强」到「Agent 进产线」

Odd Lots × Man Group CTO Gary Collier / 数据与 AI 负责人 Tushar Fernando · 2026-07-09 录制
核心数字：内部 token 消耗自 2026 年 1 月以来增长 86 倍；约 15–20 个由 AI 全流程生成的量化模型已通过人工投资委员会审核。

一、背景：86 倍不是故事的全部，只是冰山一角

开场主持人抛出的数字就足够震撼：Man Group 内部的 token 消耗自今年 1 月以来增长了 86 倍。Tushar 坦言「我们完全没预料到用量会是这样」——而且增长不是技术部门的独角戏，财务、运营、人事团队都在用 agentic coding 工作流：

"We have seen people in finance, people in operations, people in the people team using agentic coding workflows. And as a technologist, that's just super exciting to give this new capability, to see this new power to people who haven't been able to use it before."
「我们在财务、运营、人事团队都看到有人在用 agentic coding 工作流。作为一个技术人员，看到这种新能力、这种新力量落到以前用不上它的人手里，非常兴奋。」

这期对话的价值在于：它不是讨论「AI 能不能用于投资」的务虚，而是 Man Group 两位技术最高负责人现场披露一家大型主动资产管理机构里 AI 到底被怎么用——以及更关键的，alpha 到底从哪来。

二、研究增强：AI 最先改变的是信息覆盖边界

对基本面/主观投资，AI 的价值不是「替你选股」，而是解决一个长期痛点：信息越来越多，但人的时间没有变多。一个覆盖几十家公司名字的长仓分析师，要读财报、经纪研报、另类数据、播客——「一天只有几个小时，却有 50 个名字要覆盖」。

Man Group 的解法是让 AI agent 异步消化多模态信息、蒸馏出与投资论点相关的「变化」：

"So the PM can asynchronously get that insight. They could go away for a coffee... And then the agent has actually distilled a change that's happened on the internet and given them the insight that's meaningful to their portfolio, to their investment thesis."
「PM 可以异步拿到洞察，可以去喝杯咖啡……agent 已经把互联网上发生的变化蒸馏出来，把对他们组合、对他们投资论点有意义的洞察交到手上。」

最有说服力的例子：一位覆盖 AI 交易的 PM，判断行情的下一步要看「瓶颈在哪」。某个大型 hyperscaler 工程负责人在播客里说：训练模型越来越需要 GPU，但数据中心本身变得稀缺，且未来需要更强大的数据中心间网络。这个人不会参加投资者电话会，卖方研报也不会覆盖——但 AI agent 转录并合成了这段播客，让 PM 捕捉到了「GPU 稀缺 + 数据中心间网络升级」两个投资信号。这正是「AI 扩大研究带宽」的具象化。

三、Agent 进产线：15–20 个模型走完「想法→信号→验证」全流程

主持人的问题很尖锐：「端到端 agentic workflow——研究、生成想法、测试假设、甚至执行——是你们在追求的目标，还是太遥远？」答案是：不遥远，已经在跑。

量化侧已经建设了一年半的系统：多个 agent 分工——读论文和标注数据集、推理其中的经济假设 → 另一个 agent 写代码封装想法、取市场数据、跑回测 → 再一个 agent 评估前一个 agent 的输出。

"There've been a bunch, I think, 15, 20 models at the last count, that have gone all the way through. They started off as models that were ideating, went all the way through signal construction, the validation process, were reviewed and validated by a human investment committee and things like fit and proper to triage our client's assets. So this is very real, it's not make believe at this point."
「大约有 15–20 个模型完整走完了流程。它们从想法生成起步，一路走到信号构建、验证流程，由人工投资委员会审核，并符合『适当性』要求以管理客户资产。这是非常真实的，不是纸上谈兵。」

注意这个链路的关键设计：生成假设的 agent 会先写一段自然语言描述信号背后的 rationale，然后才写代码。这与后文的可解释性要求互为表里。

四、数据三层架构：alpha 的真正来源

被问到「你们的数据管线长什么样」，Tushar 给出三层架构：

1. 市场数据：高度结构化，每天仅 tick 数据就近 1TB； 2. 另类/非结构化数据：脏、格式混乱，关键是打标签、连接、统一语义； 3. 机构知识（新出现的第三层）：教会 AI 公司的流程——「正确的跑回测方法是什么」「迁移（数据）该怎么说」，让 AI「speak our language」。

被问到「前沿模型 vs 打标签数据哪个更重要」，答案直白：

"If you're looking at a coding task, you really want the latest frontier models. But for a quant research task, I think the underlying data is what fuels alpha research. Trying to just use a frontier model will get you nowhere."
「编码任务确实要最新前沿模型；但对量化研究任务，底层数据才是 alpha 研究的燃料。试图只用前沿模型会一无所获。」

所以他们的投入重点不是微调模型（只在少数场景做过），而是给数据加「颜色」：用自然语言描述告诉模型「这一行的含义是一个人进店买了一样东西」；再建一套共享语义层，让 AI 能跨数据集连接 ticker、行业、公司。这正是 Bridgewater 那篇论文的逻辑延伸：开源模型 + 专有数据 > 最前沿闭源模型。

五、模型治理：预算联邦化 + 教育，而不是自动路由

很多公司想做「把查询路由到性价比最优模型的分类器」，Man Group 刻意不做：

"We could do that. We've chosen not to... we want people to understand the dynamics of how best to use AI, and which models to use. So what we've leaned on instead is education."
「我们本来能做，但选择不做……我们希望人们理解如何最好地使用 AI、该用哪个模型。所以我们依靠的是教育。」

他们的做法：

  • 预算联邦化：去年底就按用户分类/用例预估了公司会变成什么样，今年把预算下放到各业务单元，预算可挪用（部门可以削减别处支出来买更多 token）；
  • 平台提供丰富模型选择：所有主流前沿模型 + 多个开源 open-weight 模型，但没有自动路由；
  • 透明 + 教育：公开各团队 token 消耗；发现常见低级错误——员工在同一个 context window 里「一边写投资论点、一边问午饭吃什么、一边问明天天气」；教大家把 git 这类简单工具调用拦在 LLM 循环之外，省下的成本还能「贡献回平台」。

六、86 倍的驱动：模型能力 × harness 的耦合

主持人问：从 1 月到 7 月陡增 86 倍，是模型本身变强（opus 从 4.5→4.6），还是发现了好用的「harness」（如 Claude Code）？答案：两者耦合。

"Every seven months or so, the amount of time an agentic workflow can go away and do a task is doubling. So now you can ask an agent to do a task that would take a human 16 hours... It's the scalability that has allowed larger tasks to be completed that has resulted in larger token usage."
「大约每 7 个月，agentic 工作流能独立完成的任务时长就翻一倍。现在你可以让 agent 去做要花人类 16 小时的任务……正是这种可规模化让更大的任务能被完成，从而带来更大的 token 用量。」

引用的是 METR 基准（衡量 agent 能持续工作多久）：从「写一个单元测试」到「构建整个应用功能」——任务颗粒度变大，token 自然指数增长。

七、可解释性与风控：交易必须能讲清楚

Man Group 明确表态：不是高频交易业务，持有期是「数天到数月」，因此所有交易决策必须可解释：

"We never want to be in a position where we don't know why that trade happened. The AI did it."
「我们绝不想处于这种境地：不知道为什么发生了这笔交易，只知道是 AI 干的。」

落地方式：agent 在写代码之前，先产出投资假设的自然语言描述（rationale）；再由人工投资委员会做最终把关。这与前面「15–20 个模型走完全流程」呼应——AI 负责端到端生成，人类负责最后一道验证。

八、真正的瓶颈：不是算力不是数据，是「安全地快速前进」

问「你们最缺什么」，Gary 的回答出乎意料：算力和数据「总是多多益善」，但更大的瓶颈是组织层面的——AI 能力边界扩张太快，跟上它很难；而作为受监管、负有受托义务的机构，必须在最低风险下部署：

"We need to make sure that the things we're doing, the things we're deploying are done with a minimum amount of risk. And there's a lot of work in this field that I really think the industry doesn't have answers to yet — evaluations, testing the results of AI processes, thinking about how we run agents across the business in a safe and controlled fashion."
「我们必须确保所做的、所部署的都以最低风险进行。这个领域有大量行业还没找到答案的工作——AI 流程的评估与测试、如何安全可控地在全公司运行 agent。」

「不小心删了收件箱/照片」的梗在个人场景是笑话，企业级不能发生。

九、人才与组织：指挥家、前沿部署工程师、民主化

人才门槛：Gary 表示，现在招聘任何人「无论什么岗位，都应当抬高 AI 能力下限」。而 Tushar 补充了一个更有趣的转变：技术人员要从「扎进细节」（debug、写代码）转向「指挥 agent、负责端到端流程」——像「懂技术的经理」：

"You want to be a kind of a conductor of these agents. You want to be in charge of the end-to-end process rather than necessarily being in the weeds."
「你要成为这些 agent 的指挥家，负责端到端流程，而不是陷在细节里。」

超级明星 vs 民主化：两者都在发生，但按规模看「更多是后者」——近 1800 人的公司几乎人人每天在用 AI。难点在于让多团队从「各自执行」转向「协作规划跨团队工作流」。

组织形态：当主持人提到微软的「Frontier Company」和 Anthropic 派驻 Goldman 的「前沿部署工程师」时，Gary 笑了——Man Group 大约 15 年前就是这么运作的：平台团队 + 坐在 quants 和主观经理旁边的工程师，以至于「走过交易台，你分不清谁是工程师谁是 quant」。

十、Token 经济学：从技术预算到劳动力替代

Joe 抛出 2026 年夏天市场最热的话题：软件公司叙事已转向「AI 不吃软件市场，吃的是劳动力市场」，token 支出对工资的比例就是那个 TAM。Man Group 的坦诚回答：

  • 还没开始正式讨论「工资 vs token 支出」的比例，但「到时候会来」——公司会按「哪里产出最好的经济结果」分配资源；
  • 更前沿的问题：token 越来越多是 agent 消耗的，而 agent 属于工作流，工作流归哪个部门所有？「这是我们还没解决的新问题」；
  • 两位主播的收尾判断值得一提：86x 增长而公司仍处于「鼓励实验、尚未强制节约」的阶段——这本身对 token 支出是看多信号（还没到「必须开征 token 紧缩」的时刻）。

十一、Alpha 护城河：是生态系统，不是单点

关于「AI 驱动的 alpha 会不会像 HFT 一样被竞争抹平」，Tushar 的判断：

"It is easier for people to onboard data sets, analyze them, and build features, but that doesn't mean that they can trade them. We've been doing this for decades... it's this whole network, this whole ecosystem that together, I think, drives alpha."
「人们更容易上手数据集、分析并构建特征了，但这不意味着他们能交易它们。我们做这行几十年了……正是这张网络、这个生态系统一起驱动 alpha。」

他指着一个事实：Man Group 里没有一个「alpha 代码仓库」——alpha 来自市场接入、经纪关系、独有数据、回测/算力基础设施相互作用的网络。部分数据特征会从 alpha 变成 table stakes（人人都有 → 变成风险因子），但那不是唯一的赚钱方式。

十二、局限性与说明

  • 本期为 Odd Lots 对谈，由 YouTube 自动字幕 + Google 翻译生成，人名/专有名词已尽量校正（如 Qwen、METR、Claude Code、Tushar Fernando），个别语音识别误差仍可能存在；
  • 86 倍是内部 token 消耗量（用量），不等于成本 86 倍——文中也提到员工在主动优化单次任务 token 效率；
  • 「15–20 个模型通过投资委员会」为嘉宾口径，未披露具体策略与业绩贡献；
  • Bridgewater 论文细节（用 Qwen 微调识别新闻价值）为主持人转述，可作为独立线索跟进。

一句话总结：当 AI 从「研究工具」变成「研究生产线」的一部分（token 86 倍、agent 全流程生成模型过会），Man Group 给出的护城河答案是——模型人人可得，但精心标注的数据、统一语义层、机构知识、市场接入与交易基础设施组成的网络不可复制；而组织能否「安全地快速前进」，才是决定谁能吃到这波红利的分水岭。
