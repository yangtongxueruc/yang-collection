一、为什么这场值得看

大多数关于"AI + 金融"的演讲要么停在"我们用机器学习预测涨跌"，要么沦为产品吹嘘。这场不一样：它自觉地把自己放进 scaling law 的框架里，用和 LLM 社区相同的语言（预训练语料规模、上下文长度、架构对照、speculative decoding、GPU→ASIC）来讨论金融市场，并诚实地点出金融场景独有的难题（非平稳、低延迟、事件稀疏、重尾突发）。

二、核心论点拆解

1. 市场数据是一种"类语言"的模态

Dunning 的核心类比：LLM 把 token 当作基本单位，而市场的基本单位是事件（event）。但事件和 token 并不等价：可能远小于一个 token（无信息含量的挂单），也可能远大于一个 token（多字段）。这直接引出两条研究主线：怎么压缩/表示这些事件，以及怎么处理它们非泊松、重尾、强突发的时间结构。

2. 语料规模完全够用

粗略估算：KRX 股票 feed 约 3 亿事件/日 × 250 交易日 ≈ 750 亿事件/年；十年历史 → 约 0.5 万亿事件；再叠加期货、期权、其他交易所 → 全球市场约 10× Chinchilla 参考规模的事件量。结论：做 100B–1T 参数的大规模预训练语料，在金融市场上是现实可行的。

3. 用预测目标反推模型设计

  • 内存由预测 horizon 决定：未来 T 秒 → 过去 2T 秒上下文 → 120 万事件；横截面进一步放大。
  • 速度划定智能上界："Intelligence vs Response time" 的 Pareto 曲线（nano / micro / milli / shrug）点明——挂钟延迟决定了你能用多"聪明"的模型。
  • 架构取舍：大 context 是必须的，但降采样会丢信息、attention 推断慢、recurrent 训练慢且效果差。HRT 的市场模型架构：跨品种大 context + GPU 推理 + 位置 self-attention + trade confidence 分类头与 trade price 回归头。

4. 与 LMM 域的诚实对照

把市场模型和语言模型并排比较，并承认质量"参差（mixed quality review）"：Recurrent + 简单特征 GPU 推理基本 Pass fail；大 context + cross-position + cross-symbol GPU 推理勉强 Pass。并类比了 speculative decoding、GPU→ASIC 的利润/通用性取舍、H100 PCIe vs SXM 的 Communicate→Compute 层级。

5. 合成数据与新模态融合

  • 合成数据：约 8 万亿 token 预训练语料中的关键组成；挑战在于单品种 vs 横截面、Bootstrap 问题、重尾分布、rollout 误差累积。
  • LLM Fusion：把不同市场/代码的事件流通过一条公共轴融合；研究方向包括给 LMM 加上"市场数据模态"或给市场模型加上"语言模态"，做多模态联合预训练。

6. 结论：先解市场，再外推一切

收尾很"HRT"：Scaling Deep Learning in Financial Markets 本质上就是 Scaling Deep Learning in General。潜台词：把市场这个最难、最干净的序列建模问题解好，方法论可以外推到几乎所有其他领域。
