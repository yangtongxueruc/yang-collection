一、背景：Waymo 已经"规模化"到什么程度

演讲以一组数字开场：Waymo 目前在旧金山、凤凰城、洛杉矶、奥斯汀全公开运营，每周服务 15 万+ 付费行程。配套的安全数据是基调锚点：安全气囊展开类碰撞减少 81%、致伤碰撞减少 72%、警方记录碰撞减少 57%。讲者坦承自己加入 Waymo 仅约半年，"这活儿没有一件是我的"，只是代言人。

二、为什么自动驾驶是个"难问题"

核心论点：自动驾驶在形式上很简单——两自由度系统（转向 + 加减速），难点全在"感知与理解世界"：

1. 环境极度复杂且不可控：天气多变、输入高维、大量不守规则的 agent，还要应对"非 nominal"的异常情形。 2. 长尾场景 dominate the equation：罕见事件在规模化后"不再罕见"——施工区并线、迎面卡车需倒车让行、节庆人群、坏掉的红绿灯、幼儿冲进马路、高速公路上的烧烤架、倒树、洪水…… 3. 实时 + 可靠硬约束：所有推理必须在车端、实时完成。

三、AI 怎么进来：感知 → 预测 → 规划的栈

典型栈是 传感器 → 感知 → 预测/规划 → 控制。Waymo 感知的核心理念是把所有信息聚合到一张以自车为中心的鸟瞰图（BEV），作为描述场景的中间表示。BEV 中间表示是一把双刃剑：极易泛化、可验证（方便仿真/反事实），但需要大量特征设计与人工标注。

四、模型架构：SWFormer（稀疏窗口 Transformer 做长距离 3D 检测）

感知的工程矛盾：要覆盖数百米跨度、又要厘米/毫米级精度。Waymo 的解法："两个都很糟，那就两者都要"——SWFormer，用稀疏窗口做多尺度信息聚合的 Transformer，把超长距离的稀疏点云分块聚合、再跨尺度通信。

五、行为建模：从运动预测到"把驾驶当语言"

  • 联合预测 vs 独立预测：把驾驶视为 agent 之间的"视觉对话"，用 motion-token 序列自回归生成，解码器用因果交叉注意力建模因果关系——联合预测下两 agent 不再相撞。
  • 扩散模型 Scene Diffuser：用扩散过程"边去噪边 rollout"未来轨迹。

六、规模化定律：运动的 scaling law 与 LLM 完全不同

Waymo 为 Motion LM 拟合了随参数量、训练数据变化的缩放定律：

1. 运动的 scaling law 与传统 LLM 量级上完全不同——数据分布性质变了，scaling law 就变。 2. 推理时也存在 scaling law：采样更多/更少、用更大/更小模型之间不是"越大越好"，取决于你愿花多少推理算力。

七、自动标注与 MODAR：用"未来点"补遮挡

  • 时序聚合自动标注：跨时间步聚合 3D 框，融合 lidar 几何 + 相机语义，得到全自动标注。
  • MODAR（Motion-augmented Detection And Ranging）：用运动预测把点云里的点"传送"到未来位置，生成虚拟点——对遮挡场景极有用（前车挡住后车导致没有 lidar 回波，但系统"知道车不会凭空消失"）。

八、闭环训练与强化学习：行为克隆 + RL 按需切换

多数模型在人类驾驶示范（行为克隆）上训练，真实感强但短于反事实；RL 反之。Waymo 的实用折中：在分布内用行为克隆，一旦检测到分布外（out-of-distribution）就切到 RL。例如有人从车里钻出来，行为克隆模型会贴得很近不避让，RL 模型则会主动往远离人的方向挪。

九、VLM / LLM 进驾驶：机会与短板

  • 零样本标注与蒸馏：VLM 能识别吉普、推土机并映射到 lidar 点；Gemini 微调做运动预测效果不逊专用系统。
  • 思维链（CoT）推理：先产出"等高线意图"（wait / nudge / drive forward）再执行。
  • 短板：① 空间推理弱；② 缺长期记忆；③ 实时性/算力效率需能上车。

十、工程化与落地：三个 Q&A 揭示的真相

1. AV 与 AV 的互害：夜间多车互相"礼让"导致互相按喇叭——规模化涌现的新故障。 2. 单一系统 vs 分城市定制：目前是一个系统扩展到不同地理，每次新城市按需微调；监管差异必须 case-by-case。 3. 研究模型如何接入生产栈：大模型当前只是 teacher，间接蒸馏进带安全护栏的车端模型。

` 感知(BEV/SWFormer) → 行为(Motion LM/联合预测/Scene Diffuser) → 数据飞轮(自动标注/MODAR) → 闭环(BC+RL) → 大模型(VLM/基础模型) ` 每条边都是"双刃剑"取舍：稠密↔稀疏、中间表示↔端到端、BC↔RL、单系统↔分城市。

十一、总结与启示

  • 中间表示（BEV）是工程取舍的核心，它的"需要标注"痛点催生了自动标注与 MODAR。
  • 把驾驶建模成"语言/对话" 是统一感知与行为的一条主线。
  • scaling law 不能想当然套用 LLM——数据分布决定一切，推理时算力也是可调旋钮。
  • 大模型进车是"监督/蒸馏"而非"直接接管"，安全护栏永远在 AI 组件之外。
  • 规模化会暴露训练数据里没有的故障（车库鸣笛），这是"at scale"最诚实的注脚。
