这条短短几分钟的视频，把一家极其低调、却在全美股市占有约 15% 成交量 的量化交易公司 Hudson River Trading（HRT）讲得相当通透。它既不是炫技，也不是招聘广告，而是一次"用大白话解释我们到底在干什么"的科普。下面围绕视频主线做一层展开。

一、背景：HRT 为什么会在 2002 年之后出现

视频开篇先把时间拨回 2002 年。那时候交易"已经在一定程度上自动化"，但人还在回路里——你可以想象交易所大厅里交易员扯着嗓子喊价，再靠一个人点击按钮来确认成交。与此同时，更全自动化的市场正在崛起：Island、ARCA，以及一批被称为 ECN（电子通信网络） 的小型电子交易所，成交量迅速增长。

HRT 的创立逻辑很朴素：这里显然还有大量自动化的空间可以去挖。它诞生于"半自动 + 人肉确认"向"全电子、全算法"过渡的裂缝里。这一点很重要——量化交易的崛起，本质上是交易所基础设施电子化（ECN 兴起）的结果，而不是凭空出现的。

二、量化模型的本质：是预测，不是预言

视频对"模型能做什么、不能做什么"的界定非常诚实，也顺手破除了一个常见误解：

"预测任何东西明天的价格都真的真的很难……你不该把它们想象成能未卜先知的神谕。它们没法预言说特斯拉明天的股价就会是这个数。"

HRT 的模型不是水晶球。它们真正的能力是：在任何时间尺度（一分钟、一小时、一天）上，对任何股票、期货、债券，系统性地给出"优于随机"的价格估计——或者至少是我们最好的猜测。而且这套引擎由"我们自研的 AI 模型"驱动。

这里有个值得玩味的措辞：视频用的是 AI model of our own creation。在 2026 年的语境下，"AI"这个词已经被大模型占领，但 HRT 这类公司的"AI"其实是发展了二十年的统计预测 + 最优化 + 执行系统，和今天大家谈论的 LLM 不是一回事——只是都叫 AI。

三、对市场结构的深远影响：零佣金时代

这可能是普通人最能直接感知的一点：

"散户买卖任何东西，基本上都是零成本。这和 2002 年的情况截然不同。而这其中很大一部分，要归功于自动化交易，以及像 HRT 这样的量化交易公司在市场中扮演的角色。"

这句话点出了量化做市商（market maker）的真实社会功能：通过持续提供买卖双边报价、压缩买卖价差，把交易成本摊薄到近乎为零。零售券商的"零佣金"之所以成立，底层正是因为有 HRT 这类流动性提供者在吃价差、承担库存风险。视频特意强调"不只是 HRT，而是所有量化交易公司"——这是行业集体贡献，不是某一家公司的慈善。

四、技术内核：为什么死守 C++

视频的后半段集中在工程选型上，这也是技术读者最关心的部分。

4.1 性能的两个维度：吞吐 vs 延迟

"性能有两个真正关键的维度。一个是吞吐量，也就是规模；另一个是延迟。"
  • 延迟（latency）：一条消息穿过系统要多久。交易策略的 packets 只能以光速传播，所以系统永远在"看后视镜"——对已经发生的市场事件做反应。在这个尺度上，微秒都至关重要。
  • 吞吐量（throughput）：HRT 每天要吞下约 20 TB 的流式市场数据。这既是高吞吐，又对延迟极度敏感。

夹在交易所和 HRT 之间的，是一层市场数据解析器（market data parsers）：把交易所的外部私有格式，翻译成 HRT 内部能消费的、标准化的格式。这是典型的高性能系统"适配层"。

4.2 C++ 为什么是答案

"C++ 是一门能让你达成这种低延迟、又无需逐行微优化的语言。"

这句话是精髓。很多语言能写出"够快"的代码，但要在微秒级延迟 + 20TB/天吞吐的双重约束下，还能让工程师不必把每一行都手拧成汇编，C++ 的零成本抽象（zero-overhead abstractions）和贴近硬件的控制力几乎是唯一选择。

4.3 内存安全：明知有坑，照样跳

"有些人会担心 C++ 缺乏内存安全机制。HRT 倒不是特别担心……当你想用像 C++ 这样高性能的语言时，为了达成那种性能水平，你就要在安全性上做出一定程度的妥协。"

HRT 的态度很"老派工程师"：内存不安全是这门语言自带的代价，想要性能就得接受它。怎么跨过这道坎？靠人——

"我们招募真正强的工程师，他们不仅懂计算机底层的运作原理，能把 C++ 映射到机器底层实际发生的事，还能同时写出既安全又高性能的代码。"

也就是说，HRT 用招聘门槛 + 工程文化来对冲 C++ 的安全风险，而不是靠语言本身的安全网（比如 Rust）。这解释了为什么量化巨头至今仍是 C++ 的重镇：在它们的延迟预算里，Rust 的运行时保证有时反而是"不必要的开销"。

"15%" 这个数字之所以炸裂，是因为它意味着一家非银行、非交易所、纯粹靠算法的公司，已经深刻嵌入了美国股市的流动性中枢。再配上那句收尾——

"我真心认为，如果没有 C++，HRT 不可能走到今天这一步。"

——整个视频的因果链就闭合了：电子化交易基础设施（ECN）催生了自动化需求 → HRT 用自研 AI 模型做"优于随机"的预测 → 靠 C++ 把延迟压到微秒、把吞吐顶到 20TB/天 → 最终成为占全美 15% 成交的流动性支柱。

六、关键结论与启示

1. 量化交易的社会价值被低估：它把散户交易成本压到近乎为零，是零佣金时代的隐形基建。 2. 模型是"优于随机"而非"未卜先知"：理解这一点，才能正确看待任何"AI 选股"的 hype。 3. 工程选型的本质是权衡：C++ 的内存不安全不是 bug，而是性能定价的一部分；HRT 用人才密度来买单。 4. 规模即护城河：15% 的市场份额 + 20TB/天的数据处理能力，本身就是后来者难以复制的壁垒。
