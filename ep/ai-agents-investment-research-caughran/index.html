一、背景：一个基本面投资者的「Agent 觉醒」

Brett Caughran 不是 AI 工程师，而是一个在 Tiger Cub 系基金成长、做过大量管理层调研与建模的基本面投资人。他在 2025 年夏启动了面向投资的 AI 培训项目「AI for Investment Research」，最初讲 LLM、幻觉、RAG、提示词。但到 2026 年春，他发现「怎么把 AI 用起来」的技法已经严重过时——用他的话说，是「建在沙子（sand）上」。

这一场是四场公开 webinar 的收官之作，核心回答一个问题：AI（尤其是 Agent）到底会如何改变基本面投资？ 他的立场非常克制：既不是「AI 无用论」，也不是「AI 取代论」，而是提出中间态的判断框架——外骨骼假说（Exoskeleton Hypothesis）。

二、核心论点拆解

1. 我们处在 Agent 的「演示时代」，而非生产时代

Brett 反复强调：当下谈论投资 Agent 为时过早地宣称「已落地」是危险的。关键卡点是 AI 评估（evals）远未解决——能否可靠、可扩展地把一个 firm-wide 的方法论跑起来？他的答案是否定的。但他给出一个有用的历史类比：2024 年他们 demo 了几十个金融聊天机器人，早期答案不一致、不可信；到 2025 年夏再捡起来，忽然「够机构用了」。Agent 很可能重演这条路径——现在早期、但正快速逼近可靠的生产级使用。

2. 为什么「裸 LLM」本身不适合投资研究

这是全篇最有说服力的部分。他列出 LLM 的结构性短板：不可靠的语言模型、原生不擅长数学、没有持久上下文、本质是随机的（stochastic）、难以验证、且与真实投资 workflow 脱节。更尖锐的一点是训练语料的偏见：公开 LLM 的金融语料充斥着公开博客与「Buffett 化」的价值投资叙事，和头部多空基金的思维范式截然不同；连「Claude 像投行银行家一样思考」（会自动做 plug 调平资产负债表）这种测试，都暴露了通用模型与「选股者」心智的错位。

结论很明确：把整个投资流程压进一句 prompt、用「涡轮版 Google」出一份低质量投研，是坏掉的工作流。

3. Agent 的心智模型 = 克隆你自己

他的核心方法是：不要「压缩」你的上手流程，而是训练一个专做某条 workflow 的「mini 版你」。例如「mini Brett，去给我的每个想法做反方路演（counter-pitch），每天/每周给我更新」。多个这类 agent——定位 agent、买方 whisper agent、KPI 追踪 agent、变体预期（variant perception）agent、基础比率 agent——的输出，最终抽象成一个 dashboard，让决策者面对的是「更多信息、且是更对的信息」。

4. 两个关键创新：编码 Agent 与持久运行时

  • 编码 Agent = 确定性执行层：LLM 不擅长数学，但代码擅长；LLM 去编排一个 coding agent，是他眼中这轮最关键的转折点之一。
  • 持久化 Agentic Runtime：拥有记忆、技能、工具、24×7 循环的「常驻执行」能力（他口中的 Claude Code 类持久运行时），将逐步被产品化、标准化。他强调这不是概念——已经有基金今天就在跑、烧着六位数的 token。

5. 外骨骼假说 + 2026/1/12 的「Claude Code 时刻」

Brett 把范式转移的锚点放在 2026 年 1 月 12 日 Claude Code 的发布：超级 App / agentic workspace 结构让工程复杂度被抽象掉，普通人也能搭起一个 workspace、上传数据和指令，立刻获得一个「相当好」的工具。他的判断是：投资研究将在未来 12–18 个月发生实质性变化。

他还提出 Karpathy 规则：密切关注 Andrej Karpathy 的转向——后者从「agents 是 slop」到「智能突然领先一大截」，标志着「智能过剩（intelligence overhang）」的到来。瓶颈正从「通用智能」转向「组织知识」：基础模型越强，你往上面堆的私有知识就越成为杠杆。这直接催生了他自建知识库的做法（把 38 页的「上手某只股票」流程机器可读化）。

6. 实战示例：管理层深度调研从 1 个 prompt 到 17 页机构级 deep dive

最能体现「外骨骼」价值的例子：过去你对 ChatGPT 说「给我 CEO 概览」，得到的是低质量输出；现在用一个 agent，可以把过去需要 20 个 prompt 才能完成的管理层评估（四层框架、四个 sub-agent、CEO/CFO 语言信号对齐度、回购有效性分析）编排成一个 20 步的可复现工作流，输出一份 17 页的机构级 deep dive。这「完全是另一个物种」，与聊天机器人有代际差。

7. 马赛克理论与「理解力之敌」

他借用投资界的 mosaic theory（alpha 来自多源信息的拼接，而非单一 stat），强调 AI 一键生成是理解力之敌（"AI one shot is the enemy of comprehension"）。因为投资是贝叶斯式的——市场恐慌时才有好机会，而如果你不懂业务，就没有差异化的变体视角。这也解释了为什么资深（40 岁以上）投资者反而比初级更会用 AI：他们知道痛点在哪里、知道别做什么。

8. AI 进 Excel：金融建模仍是「自行车」

他坦承对「AI 进入 Excel」的实验有点失望。模型的本质是「自行车」——必须亲自骑，用来深懂并紧密监控业务，不是按个按钮出答案。简单季度更新已相当可靠（前提是架构搭好），但「5 年没更新的复杂 resegmentation 模型」仍做不到；把 Excel 当成「模型里的分析师伙伴」分解任务，有前景但非一键成型。

9. 工具生态：从「黑客时代」到「仪表盘时代」

当前是 hacker era——各 fund 给员工 Claude Code，让大家各显神通（千花齐放）。但他预测价值会从「黑客」扩散到机构化层：三层层蛋糕 = UI/UX + 数据与研究 + 工作流上下文，后两者才是真正杠杆。当务之急是「数据可读性（data legibility）」工程——把结构化行情、财务数据、OCR、transcript，通过 MCP 接入，让 agent 读得懂你的数据。随之而来的是 buy vs build 之争：他认为金融垂直 Agent 与通用横向玩家都会长出真实规模。

10. Alpha 的形态：按认知定价，而非按事实

这是偏哲学但很关键的一段。典型 20 倍 PE 的股票，只有约 14% 的 NPV 来自未来五年——股票是按「认知/预期」定价的，这是深度行为性的。他据此论证：纯 informational edge 在压缩，但行为 alpha 与「你的世界观 alpha」仍在扩张。投资是 power law 游戏（80 年里仅 4% 的股票跑赢 T-bills），少数精英捕获大部分 alpha；而「无人类在环的 AI 对冲基金」大概率只能捕获共识视图（市场模态观点往往是负 alpha）。这反而支撑了他的外骨骼立场：聪明人把流程裹进外骨骼，而非赌 AI bot 直接抓 alpha。

11. 落地框架：红黄绿灯，且千万别压缩关键流程

他给出明确的实施纪律（red / yellow / green light）：

  • 绿灯：管理层评估类 workflow（天然有验证回路）；
  • 黄灯：财报预览（不逐条校验就交易，可能因一个 revenue 误读在盘后加仓，是真实事故）；
  • 真正的机会在「重连团队运作节奏」——新的 agentic 操作系统 + 共享 dashboard，带来 idea velocity 与流程纪律。

12. 如何开始：可重复流程 + 技能文件 + 知识图谱

落地第一步是把隐性流程显性化：因为 agent 擅长遵循指令，前提是你能写出可重复的流程。他的做法：脑 dump（Whisper Flow / Aqua Voice 口述）→ 知识图谱 → skills 层（本质是一叠 prompt 的菜单卡）。企业级则要确定性、可审计、带人工升级（escalation）的验证系统——在 demo 阶段炫酷的输出，一旦要规模化和审计，稳定性才是硬门槛。

三、关键结论（给投资从业者）

1. Agent 是「外骨骼」不是「替代品」：放大你已有的严谨流程，而不是用一键生成替代深度理解。 2. 当下是 demo era，别过早全面铺开：红黄绿灯分级，把高 stake 流程（如交易级财报反应）留到数据策略成熟后再转绿。 3. 杠杆在「数据可读性」和「工作流上下文」，而不在某个神奇模型；通用横向 workspace（Claude Code / Perplexity / Codex）会向垂直化金融 Agent 演进。 4. 瓶颈从通用智能转向组织知识：谁把自己的私有知识库、流程模板、技能文件堆得越好，谁越受益。 5. alpha 不会被 AI 杀死：按认知定价 + 行为/世界观 alpha 仍在扩张，人机协同（而非无人在环）才是正解。
