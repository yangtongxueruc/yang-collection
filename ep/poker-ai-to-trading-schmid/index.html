先看结论

这场讲座的本质，是用一条「应用强化学习（Applied RL）」的叙事线，把看似高深的概念讲「懂」：

  1. 深度学习（Deep Learning）与强化学习（Reinforcement Learning）是同一套神经网络世界观下的两种训练范式——前者给定「输入→期望输出」（监督），后者只给定「环境 + 奖励」，让智能体自己学出该怎么做。
  2. 强化学习解决的是「序列决策」问题：目标不是单步最优，而是在一段动作序列上最大化累积奖励。
  3. 现实环境太大，无法穷举求解，必须用神经网络去「近似」策略——这就是深度强化学习（Deep RL）。
  4. 金融市场在结构上就是一个不完美信息博弈（imperfect-information game），和扑克是同一类问题：隐藏信息、对手在反应、噪声巨大。这正是 EquiLibre 把扑克 AI 方法搬进算法交易的核心洞察。
  5. 今天大语言模型的「魔法」里有很大一块来自强化学习（RLHF 等）——讲座结尾绕回 LLM，解释为什么 RL 是让模型「会做事」的关键一环。

一、为什么这场讲座值得收

Martin Schmid 不是泛泛而谈的科普者。他的履历几乎是「游戏 AI → 交易」这条路径的实体化身：

  • 在布拉格查理大学数学物理学院（Matfyz，捷克 AI 人才的摇篮）读博期间，与 Matej Moravčík、Rudolf Kadlec 共同做出 DeepStack（2017）——第一个在「一对一无限注德州扑克」中击败职业人类的 AI。扑克之所以难，是因为它是典型的不完美信息博弈：你永远看不到对手的牌，要处理虚张声势（bluff）和欺骗。
  • 团队随后加入 DeepMind（伦敦），参与 「Student of Games / Player of Games」 等通用博弈算法（同时处理完美与不完美信息博弈）。
  • 2022 年离开 DeepMind，在布拉格创办 EquiLibre Technologies，把原本为扑克设计的强化学习 / CFR（反事实遗憾最小化）方法，应用到算法交易上；后来与高频做市商 Tower Research Capital 达成利润分成的「软件供应商协议（SVA）」，据公开报道其算法已通过 Tower 在标普 500 与纳斯达克上每日交易数十亿美元量级。

换言之，这场讲座是他用自己的职业故事，把「RL 到底是什么、为什么重要、又能落到哪里」串成一条线。对关心量化 / AI 投研的人来说，这是理解「博弈论 + 自学习 AI 如何进入交易市场」最好的入门材料之一。

二、为什么是「现在」：强化学习走向主流

演讲开场用了一个漂亮的类比：强化学习正在重复深度学习 10–15 年前走过的路——从纯大学的学术研究话题，转向开始对工业界、对我们日常生活产生巨大影响。

  • 他用图灵奖作为路标：2018 年图灵奖颁给深度学习三巨头（Yoshua Bengio、Geoffrey Hinton、Yann LeCun）；而「大约两年前」（即 2024 年）图灵奖颁给了强化学习之父 Richard Sutton 与 Andrew Barto。两度获奖，恰好标记了「深度学习革命」之后，「强化学习是下一波革命」的时间线。
  • 主流媒体（他举了 Forbes）已经开始把强化学习称作 AI 革命、甚至通往 AGI 的推动力。

他抛出的核心信息是：深度学习「已经赢了」，但强化学习是「站在它肩膀上的下一自然一步」，正在再次改变视觉、语言、语音、机器人等各个领域——并顺手用「今天的顶级大模型已经能拿国际数学奥林匹克金牌」来刺激台下数学系听众。

三、深度学习速成：一个大函数 + 梯度

为了让数学系听众建立直觉，他用半分钟讲清深度学习：

  • 把神经网络想成一个由许多小函数依次组合而成的巨大函数（计算图：一个函数调用下一个，数据从输入「冒泡」到输出）。
  • 训练起点是随机初始化权重；训练过程就是算梯度——即「如果把某个权重往左或往右挪一点，会让网络输出更接近我们期望的概率变大还是变小」。
  • 本质是在一个训练集上最小化误差（我们定义的 loss）。
  • 一句话总结：深度学习 = 监督学习范式下，不断沿梯度方向微调权重去逼近输入→输出的映射。

四、强化学习的定义：智能体 · 环境 · 奖励 · 序列决策

这是全场的骨架。强化学习与监督深度学习的共同点：都活在神经网络的世界里，目标都是「挪动网络权重让网络做我们想要的事」。不同点在于「任务」的定义：

  • 监督学习里，输入和「期望输出」都是明确给定的（这是猫、这是狗）。
  • 强化学习里，输出是什么我根本不知道——我只知道我想让智能体在某个环境里「做得特别好」。

形式化设定（标准的 agent–environment loop）：

  • 有一个智能体（agent），处在某个环境（environment）中，可用一组动作（action）。
  • 每当智能体采取一个动作，环境返回两样东西：奖励（reward，一个数值） 和观测（observation，环境长什么样）。
  • 神经网络（智能体）的输入是「从环境看到什么」，输出是「采取什么动作」；我们要调整权重/策略，使智能体拿到尽可能大的累积奖励。

最关键的洞察（他反复强调）：强化学习优化的是一段序列动作上的累积奖励（sequential decision making），而不只是「看一眼屏幕、按一次键就结束」。这正是它和单步预测的本质区别——有时你要在短期内「吃一点负奖励」（比如复习备考短期痛苦、去酒吧短期快乐），但从更长的最优策略看，前者才对。

两个直觉案例：

  • 国际象棋：动作 = 走子，奖励 = 终局胜/负/和（通常只在游戏结束时给 ±1/0），观测 = 棋盘长什么样。
  • 雅达利（Atari）：动作 = 按摇杆/按钮，奖励 = 游戏分数，观测 = 屏幕画面。

五、数学形式化：MDP、回报、折扣因子 γ、策略与最优策略

为了让听众「严格一点」，他把上述设定形式化为马尔可夫决策过程（MDP）：

  • 用图建模：顶点（vertex）对应状态（state，或智能体可能所处的位置），边对应「在某状态采取某动作后能到达的下一状态」。
  • 形式化要素：状态集合、动作集合、转移概率（从状态 A 经动作到各状态的概率分布）、每步奖励。
  • 回报（return） = 一段序列上奖励之和；常带折扣因子 γ（gamma）——近处的奖励比 100 步之后的奖励更重要（也有理论上的必要性，使「最优策略」在某些环境下有意义）。
  • 策略（policy） = 在每个状态下对各动作的概率分布；它就是智能体的「打法」。
  • 一个重要结论：在单智能体环境下，存在使累积奖励最大的「最优策略」（不存在比它更大的策略）。多智能体时则不同——你的回报不只取决于自己的策略，还取决于对手怎么打（下棋时要看对手）。

他用 David Silver 那张经典幻灯片类比：学生面对「短期负奖励（复习）vs 短期正奖励（去酒吧）」，但从更长序列看，忍过短期负奖励、通过考试拿到大正奖励才是最优策略。

六、现实必须近似：状态爆炸 → 神经网络 + RL = 深度 RL

小环境（小到能画在屏幕上、能在电脑里跑算法）可以用精确算法收敛到最优解。但真实世界的环境大到放不进计算机：

  • 仅国际象棋（更别说围棋）的状态数，就超过宇宙中的原子数。所以永远不可能靠堆算力把真实问题「彻底求解」。

因此必须近似（approximate）——而这正是神经网络与强化学习天然契合的原因：

  • 小环境里你只需要一张小表格 + 一个 for 循环就能更新策略，根本不需要神经网络；
  • 一旦状态图大到放不下，你才需要神经网络去近似那个「状态→最优动作」的函数。
  • 把 RL 与 DL 结合，就叫深度强化学习（Deep RL）。

七、历史突破：Pong → AlphaGo → 扑克 → 规模化 → 瓶颈

讲座中段梳理了应用 RL 的「突破史」（时间线与其内容一致）：

  • 第一波爆发（约 2012–2015）：DeepMind 用 RL 在 Pong / Atari 上「魔法般」自学出策略，当时震惊了很多人；随后在 AlphaGo / 围棋（2016） 上突破——曾被认为还要 20 年才能超越人类。
  • 扑克（不完美信息）：扑克不能像围棋那样「全信息摆在棋盘上」，必须用 CFR（反事实遗憾最小化） 一类方法去逼近纳什均衡；DeepStack 是代表。讲座把 Pong 的简单思想一路「规模化（scale）」到大型计算机游戏。
  • 规模化（scaling）：把同样的思想放大到更多机器、更大的网络——他提到 OpenAI 的 PPO 算法（讲座里称 slide 10 的 PPO 与 OpenAI 的成果「没有本质不同，只是放大了网络和机器」）。
  • 瓶颈期（他戏称为「饥饿与霍乱 / hlad a cholera」）：当大家把原有技术跟深度学习简单结合、再一味「朴素规模化（naive scaling）」时，会撞上规模化的极限——这一时期并不一帆风顺，需要新方法才能继续前进。

八、从扑克到交易：市场即不完美信息博弈

这是全场的落点，也是与「量化 / 算法交易」最直接相关的部分。问答环节里他讲得很实在：

  • 金融市场在结构上就类似扑克：参与者隐藏信息（你不知道对手的仓位）、会「虚张声势」、要推断「其他 agent 在想什么」。市场里同样充满噪声——你赚了钱，可能是因为你打得好，也可能只是「牌好（运气）」，这点和扑克一模一样。
  • EquiLibre 的做法：把从游戏里来的自学习 RL / CFR 方法，应用到算法交易。与传统量化的区别在思路——传统统计套利/预测模型假定「历史会重复」，一旦市场突变就失效；博弈论思路不试图「预测未来」，而是把市场参与者的互动建模成博弈，求一个即便对手激烈反应也仍盈利的、不可利用（unexploitable）的策略（纳什均衡视角）。
  • 与 Tower Research Capital 的合作：EquiLibre 作为独立公司，不直接用自己的账户交易，而是通过 SVA 把算法/软件授权给 Tower，借 Tower 的交易所接入与基础设施，按利润分成；据称其算法已在标普 500 / 纳斯达克上每日交易数十亿美元量级。
  • 挑战（他亲口承认）：金融数据噪声大、样本有限，任何被你 exploit 的模式都会因别人竞争、因经济 regimes 切换而漂移——不能简单把视觉/游戏/语音里现成的学习算法 naive 地搬过来。
  • 对未来的判断：今天市场已经满是（非 AI 的）自动化 agent；EquiLibre 想做「第一家真正建立在现代 AI/RL 方法上的交易公司」。他预测 5–10 年后一切都会自动化，且所有人都不得不采用这些「好得多」的现代方法。
  • 巴菲特类比：巴菲特做的是「投资」（长期视角、优化不同目标函数），和毫秒级「交易」（让市场有效、不剧烈波动）是两回事——目标函数不同，不能混为一谈。
  • 他还提到：自动化交易在「市场疯狂/恐慌」时最舒服——因为恐慌意味着大量人非理性、市场看起来很「无效」，而这恰是系统化策略最大的机会窗口（同时他也承认这只是统计性规律，未必对下一次事件成立）。顺带吐槽欧洲在开源/闭源模型上都「处境糟糕」。

九、绕回 LLM：RL 是「魔法」的来源

讲座首尾呼应：开头说「希望你们以后用 LLM 时，能多一分直觉——那股 magic 里强化学习做了什么」；结尾回到这点。核心信息是——

  • 今天最强的语言模型之所以「会做事、会遵循指令、会推理」，很大一块能力来自强化学习（典型如 RLHF / 基于偏好的强化学习），而不只是预训练的自回归下一个词预测。
  • 原因正在于第四节讲的那句话：RL 解决的是序列决策——生成一段回答、一步步推理，本质上也是在「一段序列动作上最大化某种奖励」。

关键结论 / 趋势

  1. RL 是继 DL 之后的下一波范式，已从学术走向主流（图灵奖为证）。
  2. 「近似 + 神经网络」是 RL 落地的关键，状态空间爆炸使精确求解不可行，深度 RL 是必然组合。
  3. 博弈论视角正在进入交易：把市场当不完美信息博弈、求不可利用策略，是 EquiLibre 这类团队的差异化路线；但它高度依赖「方法真的比传统量化好得多」这一未被充分验证的前提。
  4. RL 也是 LLM 能力的隐藏支柱：理解 RL，才能理解今天模型「为什么行」。
